# Modelling PDFs

This folder collects every modelling-related report for the marine-risk
platform. Start with the call deck, then drill into the component reports.

## Start here

| PDF | What it covers |
|---|---|
| `iwc_modelling_briefing.pdf` | **Call deck.** Current modelling, tests, reviewer points answered, and the IWC-conformity roadmap. Plain-language + technical at each stage. Generated by `docs/generate/generate_iwc_call_deck.py`. |

## IWC alignment

| PDF | What it covers |
|---|---|
| `iwc_strike_risk_alignment.pdf` | Alignment of the strike-risk model with the IWC reporting standard (Leaper et al. 2026), incl. R. Leaper feedback. |
| `iwc_sdm_alignment.pdf` | Alignment of the SDM / abundance approach with IWC model-based estimation guidance (Miller & Kelly 2023). |
| `sdm_modelling_guidelines.pdf` | Source: IWC SDM / abundance guidance (reference doc, no generator). |
| `RS17562_SC_68B_HIM_09_rev1.pdf` | Source: IWC SC/68B/HIM/09 (reference doc, no generator). |
| `strike_risk_method.pdf` | Source: IWC strike-risk reporting standard (reference doc, no generator). |

## Regenerating

Each report (except the three IWC source docs) has a generator in
`docs/generate/`. Run from the project root, e.g.:

```bash
uv run python docs/generate/generate_iwc_call_deck.py
```

Generators write directly into this folder.
